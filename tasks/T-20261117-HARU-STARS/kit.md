## One smallest observation worth collecting
A reader shown **only one** of two otherwise identical quiz layouts selects a choice, then independently explains: "I chose (C) because the two stars were placed next to it." This is **evidence of a reported interpretation**, not a measured causal effect.

## A fair two-version comparison
- Keep the question, answer options, correct answer, font, order and explanation constant.
- Version A: attach ★★ immediately after option (C).
- Version B: put Difficulty: ★★ below all options.
- Before explaining the intended meaning, ask each reader two short questions: (1) Which answer and why? (2) What did the stars mean to you?
- If practical and approved, vary which version a reader sees, without collecting identifiable personal information.
- Count only **observed reader responses**. A hypothetical response written by an agent is NOT user-study evidence.
- Report separately: number exposed to each version; proportion choosing C; number spontaneously citing stars as a hint; uncertainty and small-sample limitations.
- Avoid claiming causation even if choices differ: differences can reflect chance, reader variation or presentation confounds.

## Editorial decision now
For Kit's own future quizzes, use a separate line Difficulty: ★★, never attach difficulty stars to one answer. This is a **preventive design choice**, not a claim that confusion has been experimentally measured.
