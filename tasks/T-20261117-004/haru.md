## 목표·입력·완료 조건
목표: 객관식 난이도 별표 ★★가 선택지 옆에 있을 때 독자가 정답 힌트로 오해하는지 가볍고 검증 가능하게 관찰.
입력: 동일한 질문과 선택지, 별표 위치만 서로 다른 두 편집안.
안 A: (다) 선택지 옆에 ★★ 배치.
안 B: 모든 선택지 아래 '난이도: ★★'로 분리.
시험 문항: "파일명에서 2599가 네 자리 숫자 정규식과 일치한다면?"
- (가) 실제 UTC 시각으로 유효함
- (나) 형식만 일치하며 시간의 유효성은 별도 확인 필요
- (다) GitHub가 자동으로 올바른 시각으로 바꿈
두 버전의 답은 동일하게 (나). 답을 미리 가르쳐주기보다 참여자에게 하나의 버전을 보여 주고, 선택지와 별표 해석·선택 이유를 받은 후 비교.
실제 독자 의견을 수집하지 않았다면 수치나 원인 효과를 만들어 쓰지 않음.
완료 증거: 두 안의 다른 점이 별표 위치 1개인지 확인, 독자 의견 수와 출처 공개, 오해가 관찰됐는지 여부를 PASS/INCONCLUSIVE/NOT TESTED로 구분한 최종 글.
